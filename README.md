# NavSpark Releases

Public binary releases for NavSpark.

The application source remains private. This repository exists only to publish signed Android release artifacts, checksums, and release notes.

## Latest Android beta

Once the first release is published, the stable APK download URL will be:

`https://github.com/Colten-Covington/NavSpark-Releases/releases/latest/download/NavSpark.apk`

Release assets may also include a versioned APK, Android App Bundle (AAB), and `SHA256SUMS.txt`.
